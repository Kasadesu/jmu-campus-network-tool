# JMU 校园网配置工具

集美大学校园网（`JMU-STU`）Windows 客户端的网络配置切换工具与脚本。

用于解决**晚上在宿舍楼区无法完成 ePortal 认证**的问题。

---

## 使用方式

项目提供两种使用方式：**桌面客户端**（推荐，功能更完整）和传统的**批处理脚本**。

### 方式 1：使用桌面客户端 (`JmuNetHelper.exe`)

单文件绿色程序（约 85 KB），双击即可运行，依赖系统自带的 .NET Framework 4.8，不需要额外安装运行库。

主要功能：
- **静态 IP 切换与自动分配**：内置多个内网实测可用的静态 IP。如果不确定哪个能用，下拉选择「自动分配最佳 IP (智能优选)」，工具会自动测试并绑定通畅的节点。
- **切完自动登录**：填写学号与密码后（通过 Windows DPAPI 加密保存在本地，不存明文），切换静态 IP 成功会自动在后台完成 `10.8.2.2` 网页认证，无需再开浏览器。
- **解决 Win11 假死与 IP 冲突**：切静态 IP 时自动设置 `dadtransmits=0`，避免 Win11 把学校网关的 Proxy-ARP 误判为 IP 冲突导致网络假死。
- **秒切不卡顿**：优化了 DNS 配置命令，跳过系统无意义的网络探查，切换过程不会再卡十几秒。
- **托盘常驻**：平时可最小化到右下角托盘，右键即可在「校园网静态模式」与「恢复自动获取 (DHCP)」之间一键切换。

---

### 方式 2：使用批处理脚本

如果不想开图形界面，可以使用 `scripts/` 目录下的批处理脚本。右键管理员身份或双击运行：

| 脚本 | 作用 | 什么时候用 |
| --- | --- | --- |
| `scripts/apply-campus-config.bat` | 应用校园网配置 | 在宿舍/学校，要用校园网时 |
| `scripts/restore-dhcp.bat` | 恢复自动获取 | 离开校园网、去连别的 WiFi 时 |

#### 脚本执行内容：
1. 清理旧的校园网路由
2. 关闭网卡 DAD 检测 (`dadtransmits=0`)，防御 Win11 误判冲突
3. WLAN 设为静态 IP 与网关 `192.168.128.1`
4. DNS 设为 `172.17.8.32` / `172.17.8.33`
5. 写入持久路由：`10.0.0.0/8`、`172.17.0.0/16` → `192.168.128.1`

> 脚本内置 SSID 检测：不在 `JMU-STU` 下运行时会弹出警告确认，避免在其他 Wi-Fi 下误操作断网。

---

## 重启之后

- 静态 IP、DNS、持久路由**都会保留**。
- **认证会失效**，需要重新登录：连上 `JMU-STU` 后，在客户端中点「登录认证」，或打开浏览器访问 `http://10.8.2.2/`。

---

## 遇到问题

认证页打不开、配了还是上不了网、校内资源不通、Win11 出现 IP 冲突等情况，详见 **[docs/troubleshooting.md](docs/troubleshooting.md)**。
