# JMU 校园网配置工具

集美大学校园网（`JMU-STU`）Windows 客户端的网络配置切换脚本。

用于解决**晚上在宿舍楼区无法完成 ePortal 认证**的问题。

---

## 一、认证页地址

```
http://10.8.2.2/
```

未认证状态下，用浏览器访问任意 **http** 网站也会自动跳转到认证页。

> **必须用 http，不能用 https。** HTTPS 流量无法被劫持改写，不会触发跳转。

---

## 二、使用方法

两个脚本成对使用。**双击运行** —— 会自动请求管理员权限，弹窗点「是」，然后按 **Y** 确认。

| 脚本 | 作用 | 什么时候用 |
| --- | --- | --- |
| `scripts/apply-campus-config.bat` | 应用校园网配置 | 在宿舍/学校，要用校园网时 |
| `scripts/restore-dhcp.bat` | 恢复自动获取 | 离开校园网、去连别的 WiFi 时 |

### 应用脚本具体做了什么

| 步骤 | 内容 |
| --- | --- |
| 1 | 清理旧的校园网路由 |
| 2 | WLAN 设为静态 IP `172.19.245.138/24`，网关 `192.168.128.1` |
| 3 | DNS 设为 `172.17.8.32` / `172.17.8.33` |
| 4 | 写入持久路由：`10.0.0.0/8`、`172.17.0.0/16` → `192.168.128.1` |
| 5 | 打印当前配置，供你核对结果 |

脚本内置 SSID 检测：当前不在 `JMU-STU` 时会先警告并要求二次确认 —— 这套配置在别的网络下应用会直接断网。

### 重启之后

- 静态 IP、DNS、持久路由**都会保留**
- **认证会失效**，需要重新登录：连上 `JMU-STU` 后，打开浏览器访问 `http://10.8.2.2/`，输入学号密码
